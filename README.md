# CoolTouch for Mac

An external touchscreen can display your Mac even when tapping it does nothing. CoolTouch adds touch input and gestures to compatible external USB touchscreens.

[Watch the touchscreen demo](https://cooltouch.app/#real-demo) · [Download 2.2.1 for Mac](https://github.com/marscitizen33/cooltouch-releases/releases/download/v2.2.1/CoolTouchDriver-v2.2.1-macOS.zip) · [2.2.1 release notes](https://github.com/marscitizen33/cooltouch-releases/releases/tag/v2.2.1)

## What you can do

- In Preview, swipe a PDF to scroll and spread two fingers to enlarge the text.
- In Finder, tap to select, double-tap to open, or hold a file to show its menu and drag it.
- In Chrome, pinch over text to zoom the page. Pinch inside a supported embedded map to zoom the map independently.
- In Photos, pinch an open picture to zoom in steps. In Apple Maps, turn two fingers to rotate the map.

## Get started

You need an Apple silicon Mac running macOS 15 or later and a compatible external USB touchscreen. Connect both video and USB touch input. Some displays carry both over one USB-C cable.

Unzip the download, move CoolTouch to Applications and open it. Grant Accessibility permission when prompted. Follow the touch check if it appears, and choose the target display if asked. Activate with the license key from your [Gumroad purchase](https://app.gumroad.com/library).

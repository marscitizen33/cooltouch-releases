# 市场运营交接

目标是让拥有外接触摸屏的 Mac 用户看到实际效果，了解兼容条件，并用自己的屏幕尝试。英文渠道默认用英文，对负责人用中文。

| 时间 | 工作 | 交付 |
| --- | --- | --- |
| 接手当天 | 阅读 COPY.md、观看两支视频，对照官网和购买页，确认版本及条款 | 一段产品定位、适用人群、待确认问题 |
| 首周第 1 条 | 用真实视频展示“有画面，点了却没反应”的场景 | X 帖文、视频、试用入口 |
| 首周第 2 条 | 用向导截图说明视频线与 USB 触摸输入、首次设置 | 教程帖、图片和替代文本 |
| 首周第 3 条 | 从 Preview、Finder、Maps 中选一个任务讲清楚 | 一条具体用例及下周选题 |
| 每周复盘 | 按平台实际可见的数据比较曝光、链接点击，以及用户询问的设备或兼容问题 | 中文周报，注明时间范围和数据来源；无法归因的试用或购买标为未知 |

默认由 agent 提案、负责人在私聊确认渠道与稿件后发布。已另行授权自动发布的渠道按该授权执行。涉及改价、优惠码、退款承诺、付费投放或联系客户时单独确认。账号及统计数据使用私有运营空间管理。

每条稿件交付正文、对应素材、无障碍替代文本、目标链接和期望用户完成的动作。反馈整理到私有周报，公开材料只更新经核实的产品事实。
